# 《绿茵世代》v9.0.0：2亿次轻量级事件校准报告

测试日期：2026-11-13（新加坡）
实验代码：`tests/v9-100million-events.cjs`，在 GitHub Actions Node 22 中实际执行。
固定种子：`0x2a6b3f91`；两个版本分别各执行 **100,000,000 次** 事件抽样，总计 **200,000,000 次**。

## 重要范围限制

这并非一亿场完整比赛，更不是一亿个完整球员生涯。每轮实验覆盖 7 类身高/体重组合 × 8 个场上位置 × 3 种职业发展路线 × 4 种模拟事件 = 672 个均衡单元。

- **争顶 / 身体对抗 / 灵活**：以50%为共同参照，根据 `BodyPath.profile()` 的参数调整各事件概率，然后由独立伪随机数决定结果。这是**控制条件下的参数校准代理指标**，不能称为现实比赛胜率或游戏完整对局实绩。
- **首发**：由 `CareerDepth.lineup()` 计算实际游戏所用首发概率，再用同一个测试种子抽取二元结果。未把额外的“进入比赛名单”的概率混同进去。
- **位置适配**：直接从 `BodyPath.matchup()` 读取参数，不是单独的事件抽样结果。
- 每个版本严格执行1亿次随机事件，而不是通过百分比乘出一个虚构样本数。正式游戏另有完整赛季和双主角回归测试。

上述每组体型，在每种事件类别各有约 357 万次独立抽样（与位置、路线均匀交叉）。两轮中灵活性最强仍为矮轻体型，争顶和单次身体对抗最强仍为超高偏重体型；但 **没有一种体型能在所有维度占优**。

特别校准：超高偏重体型作为中后卫的 `matchup()` 系数，从 1.0829 降至 1.0366（来源为游戏公式、不是随机统计）；身体较重的额外体能消耗随质量增大进一步体现。

## 生涯路线的首发概率

| 开局路线 | v8.1 | v9.0 |
|---|---:|---:|
| 均衡发展 | 59.50% | 59.38% |
| 成长优先 | 57.49% | 58.37% |
| 出场优先 | 66.99% | 63.37% |
| 出场 - 成长差值 | 9.50个百分点 | **5.00个百分点** |

调校目标：依旧让两种路线产生可感知差异，同时避免出场优先在每一年获得不可逆的过大先手；成长优先的训练升级阈值优势也从原来偏大的两极差异适度收窄。

## v9.0 正式实施的修改

1. **身体模型按场上位置动态调权**：中卫更注重防守对抗与高球，但必须为灵活性支付代价；边锋的灵活优势保持有效。
2. **极端体型的收益封顶**：加大体重的体能代价，适度减小超级身高与体重同时给中卫带来的综合增益。不会更改隐藏潜能或直接给球员整体能力加分。
3. **成长优先／出场优先重新平衡**：首发、入场、训练阈值都保留优先区别，但不再叠加过强。
4. **比赛中实实在在生成简化对抗**：根据本人位置、体格和实际出场分钟，模拟最多3次高空球、身体对抗、变向或门将高球处理，并在比赛结果中保存、展示；这些是**新生成的游戏事件**，不是历史真实比赛数据，不额外虚构进球。
5. **老存档按中性体格运行**：缺失真实存档身高或体重的旧人物，不会被自动赋予体型优势；原比赛历史、年龄、获奖、转会及十张卡等数据不重写。

## 仍未由本次实验证明的事情

- 1亿次微事件不能证明真实比赛中某一身高的最佳胜率，也不能替代完整生涯、转会、金球奖与球队积分平衡检查。
- 模拟的争顶、身体对抗与变向是游戏抽象，不等同于追踪摄像机产生的真实动作。
- 现有引擎依然先计算球队比分再分配球员贡献；v9.0 的体格挑战主要影响个人评分微调与可见事件记录，没有将每次对抗硬生生改写为球队进球，避免一球多算。
- 参数仅用于游戏平衡，不以性别、种族、族裔、肤色或国籍推定身体素质或运动能力。

## 复现实验

从仓库根目录执行：

```bash
node football-legacy/tests/v9-100million-events.cjs
```

终端将输出 `FOOTBALL_V9_CALIBRATION_JSON=` 开头的完整 JSON，其中包含全部七种体型、八个位置的适配系数和三条生涯路线的统计。

该实验固定条件、固定种子，可用于之后 v9.1、v10 比较；**不要**只根据一个版本的冠军或进球次数判断体型平衡。
