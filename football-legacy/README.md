# 绿茵世代 Football Dynasty v4.5

本次整合以本版生涯引擎为基础，吸收旧版的赛前建议、保险备份和手机操作体验；修复主客场策略、伤停时策略及能力点分配。保险备份与自动存档都保存在当前浏览器，请定期导出 JSON。旧版 v2/v3 存档与 v4 格式不同，不能直接导入，原存档不会被修改。

这是一个重新开发的独立静态网页足球生涯模拟游戏，面向安卓平板横屏与电脑浏览器。**不读取或转换以前的《绿茵传奇》v2/v3存档**，浏览器存储键为 `football-dynasty-v4-independent-20261101`。

**试玩地址：** https://wpcnb.github.io/order-classifier/football-legacy/

## 开局

- 默认剧本：2026/27赛季、22岁、中国籍、左边锋“陆白”，在游戏平行世界替换拉什福德进入曼联9号位置。替换是游戏设定，不代表真实转会。
- 自定义剧本：选择姓名、国籍、位置、青训联赛和青训俱乐部，并可随机重抽7项基础天赋与潜力。
- 曼联2026-11-01之前的9场英超结果锁定，开档9场1胜4平4负、7分。**2026/27欧冠全部144场对阵和已经踢完的54场结果**来自欧足联公布的数据（联赛阶段前3轮）；36支球队因此各已踢完3场。曼联同期欧冠3场1胜2负、3分。
- **除已明确锁定的曼联英超9场和欧冠前3轮全部54场以外，其他历史时段球队积分和比赛属于游戏模拟，**不可当作2026/27真实联赛积分榜**。**

## 当前可玩的机制

- 五大联赛、荷甲、葡超、中超、巴甲；按各自球数进行完整主客场双循环，英超38场、德甲34场、中超30场。
- 默认曼联2026/27英超38场对阵表按已公布的顺序排布。其他赛季/联赛采用程序生成的完整双循环。
- 欧冠、欧联：36队、8场联赛阶段；前8名直通16强、9-24名附加赛，附加赛及16强/8强/半决赛两回合，决赛一场。
- 国内杯赛、国家队及亚洲杯/欧洲杯/世界杯的简化小组与淘汰机制。
- 逐场操作、三场快进、一键模拟完整剩余赛季；所有赛事仍然逐场计入记录。
- 根据位置分配属性、教练成长加点和恢复训练；可选择自动分配或手动加点。
- 赛季间转会：不允许已升一线队的球员重新签回青训队；国家队固定由国籍决定。
- 九个联赛平行推进，超过1500名AI球员逐场累计联赛/欧战数据、衰老、退役接替与跨队转会，俱乐部实力随赛季变化；可打开世界足球界面查看积分、射手/助攻榜与各赛季冠军。
- 金球奖按真实计分规则模拟100名记者，100份选票可以逐个展开查看，支持导出CSV供WPS打开，保存历代金球奖评选记录。同分按第一名票数等顺序排序。
- 欧冠/欧联得分王、助攻王、联赛金靴、助攻王、年轻球员、最佳球员等按照模拟球星实际表现评选，不再只看固定进球阈值。
- 32岁后可：退役并直接开启下一代、退役执教并立即开启下一代，或**独立进入主教练模式**。主教练能调整阵型、用预算搜寻并签约球员、管理董事会信任、获得俱乐部执教邀请，也能将来开启儿子生涯并让父亲执教同队。历代履历完整保存。
- 新增伤停、黄牌累计停赛、红牌停赛、位置化训练、伤病恢复、比赛技术统计和赛后完整战报（同一场战报重新打开不会随机变化）。
- 自动浏览器存档与 v4 JSON 导出、导入。

## 已知边界

这是可玩的原创模拟器而非商业版FC/FM或官方球员数据库：除已明确注明的曼联英超和欧冠联赛阶段历史比赛，其余球队战绩、其他球星表现、未来赛季和奖项为**游戏生成**；不提供自动联网实时更新、真实球员肖像授权和全世界完整官方球员数据库。**未来赛季的欧冠抽签、国际赛事资格与部分赛历仍是合理化模拟，而非完整国际足联/欧足联官方规则复刻；国内杯赛和国家队赛事采用简化赛程。**真实已完赛比分会在游戏内明确标注，避免混淆。

## 文件说明

- `index.html` — 独立平板UI与视觉样式
- `game.js` — 完整赛程、九国联动、AI世界、比赛、训练、奖项、转会、主帅、多代传承和存档逻辑
- `uefa2026.js` — 官方2026/27欧冠144场对阵及截至11月1日的54场历史比分
- `assets/stadium.svg` / `assets/footballer.svg` — 本地原创建筑和球员插画，不依赖外部图片服务
- `tests/smoke.cjs` — 自动化回归测试，GitHub Actions每次更新运行

### 本地开发

直接用静态服务器运行本目录，例如 `python -m http.server 8080`，从浏览器打开 `/football-legacy/`。无依赖打包；无需账号登录。
