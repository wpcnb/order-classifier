版本规则：以 S1.00 为基准，每次正式更新递增 0.01（S1.01、S1.02、S1.03……）。旧存档存储键及 JSON 导入格式保持不变。

## S1.11 三剑客个人评选

第三名球员升入一线队后，所在联赛也会评选金靴、助攻王、金手套和最佳年轻球员。满足出场、位置及表现门槛时，还可获得欧战最佳射手、欧战助攻王及世界年度最佳阵容。人机使用已保存的逐场评分参加评选。金球奖和世界足球先生沿用共享投票，入围后两份榜单都会标出人机。球员卡可以打开个人荣誉，按赛季查看获奖项目和入围名次。旧档可查已保存的年度榜单和最佳年轻球员得主，其余个人奖从新结算的赛季开始记录。

## S1.10 人机赛季荣誉履历

在人机球员卡查看当季俱乐部冠军，展开「查看人机生涯履历」可按赛季回看奖杯、连续无冠季数和转会去向。联赛、国内杯赛和欧战分别列出，同季多冠会一并记录。青训赛季和中途加入的赛季另行标明。旧档保留已有记录，从下一次结算起记录具体奖杯。

## S1.09 人机一线队生涯

开局可填写第三名球员的姓名，已有生涯可在人机面板修改。人机满 18 岁升入青训母队的一线队，读档时也会补办成年球员的毕业。面板分别显示出身青训营和当前球队。

人机连续三个完整的一线队赛季未获联赛、国内杯赛或欧战冠军时，自动转入另一支同档球队，决定在赛季总结公布，下一季生效。夺冠或完成这次同档转会后重新计数。第三个无冠赛季优先执行同档转会，其余赛季沿用表现升降档规则。青训和中途加入的首季不计，退役前最后一季按原规则不再转会。

## S1.08 绿茵三剑客2

人机球员和两名主角共用位置考核、球探通过率、连续低迷计数及十张转会卡。中锋看进球与助攻，门将与后卫按扑救、防守和评分考核。连续两季触发低迷且球队高于最低档时自动抽取下一档球队；青训、出场少于 22 场、伤停以及 35 岁起均豁免低迷考核。升档仍有九张下一档和一张幸运跳档卡（只剩一档时十张均为最高档）。无升降档时，人机偶尔在符合主角同档转会条件的球队中选择。决定在赛季总结公布，新赛季生效，读档沿用原决定。

S1.07 存档可直接继续。当季已踢比赛使用存档中的出场与表现总计，新踢的比赛另外记录位置动作、实际比分和评分。过去赛季的转会历史保留。

## S1.07 绿茵三剑客

开局选择「一键开启三人生涯」，保留两名主角，自动抽取青训球队，并从同一联赛的青训营招入第三名人机球员。人机的国籍、位置、天赋潜力、身高、体重、家境与青训营在加入时随机生成并保存。家境是人物背景。人机使用共享球员名单和比赛比分累计出场、进球和助攻，休赛期自动成长、毕业或转会。

「一键模拟一季」推进到赛季总结，「连续模拟生涯」跨赛季自动推进，可在赛季之间暂停。两名主角自动训练、加点、处理中期事件并接受抽到的转会报价，人机按共享联赛规则自动发展。旧双人存档可在生涯主页选择「加入人机球员并自动模拟一季」，人机从当前赛季加入。

## S1.06 专项训练进度结转

自动备战和手动专项训练按实际升级门槛扣除进度，多出的点数留给同一名球员、同一项能力的下次训练。深度生涯的训练中心显示当前进度和升级门槛。例：门槛为 7 时，6 点进度加 3 点强化训练，能力提升 1 点，留下 2/7。达到成长上限时停止累计。已有存档沿用现存进度。

## S1.05 长期生涯年度评奖

同一球员以唯一身份参与金球奖计票。新生代球员和双人主角凭当季出场进入候选池，满十人时仍由一百名记者各选十人，共计 6700 分。有出场记录的不同候选人不足十人时，两人履历同步记录本届空缺，联赛荣誉与下赛季照常结算。历史奖项保留原记录。回归覆盖 2035、2040、2048、2055 年边界存档。

## S1.04 绿茵信仰之亢龙有悔

两名球员分别制定当季备战方案，可随赛程调整。强化成长用更多体能换取单次训练进度；体能优先让自动备战更早休息，手动专项也更轻。青训、成年、老将沿用各自成长上限。旧档和新赛季默认为均衡备战。

生涯主页展示当季已记录的比赛分钟、因伤缺席场数与体能，赛季结束后将出勤摘要保存在本人履历。转会揭牌及同档报价列出以当前状态估算的留队与加盟后首发率，取自比赛引擎在球员已获出场资格时使用的同一模型。

后续平衡优化按年龄、位置、球队实力分别比较三种方案的能力增长、赛季出场分钟与伤缺，检查是否有一种方案在所有阶段同时占优。转会比较使用已经揭晓的球队。验证入口为 `node football-legacy/tests/lateral-training.cjs`。

## 本次评奖机制优化（2026-11-18）

不新增版本名称，不改变浏览器存档键、JSON 导入格式或已保存的历史颁奖记录。新结算使用金球奖 `model=9` 和 FIFA The Best `model=2`。

年度欧战荣誉来自唯一共享欧冠/欧联赛事及球队淘汰赛战绩：欧冠冠军基础30分、亚军16分、四强9分；欧联冠军16分。球员凭当年欧战实际出场比例取得相应加分，国籍不影响权重，未获得欧战冠军仍可凭其他赛季成绩获奖。五大联赛冠军依旧计分，累计历史奖杯不会再次加入当年的评选。

金球奖在进球、助攻、出场和球队荣誉外，采用相同表达式校准 NPC 与受控球员的赛季评分，并给门将及防守球员一定零封贡献；FIFA 四类选民不再过度依赖静态能力分。金球奖记者票数与积分规则保持原样。配套测试为 `node football-legacy/tests/annual-awards-regression.cjs`，随项目 GitHub Actions 自动执行。

## 当前玩法

两名球员拥有独立的成长、伤停、转会和荣誉，共用同一个足球世界、赛程与赛事结果。经典双人开局从 16 岁青训起步，18 岁进入所抽俱乐部一线队；自定义人物的资料与能力属于游戏设定，并不代表真实运动员的足球能力。

开局时两人可以分别输入姓名或选择预设人物，并自主选择中超或英、西、德、意、法五大联赛作为起始联赛，然后各自从随机生成的十张球队卡中亲手翻开一张。球队由卡牌随机决定，翻开后保存。中超固定，不模拟中甲、中乙升降级。

## 成长与转会

- 球员达到升档资格后，十张转会卡由九张下一档球队和一张再上一档的幸运球队组成；距离最高档只差一级时，十张均为最高档。降档卡均来自对应的目标档次。球队分档和实力数值为游戏设定。
- 两人分别选择卡牌和去留，也可以处理符合条件的同档转会；连续两个赛季无冠只提醒，不自动强制换队。训练和日常赛事可自动推进，球员可以选择训练方向。
- 伤病、黄牌、红牌和停赛在游戏中模拟；伤停恢复与赛事停赛按存档记录处理。身体能力不早于 35 岁开始明显下降，球员满 40 岁自动退役，一人退役后另一人的职业生涯可以继续。
- 用户选择的双人封面是合成画面。部分历史赛果会标明来源，其余赛果以及转会、能力和荣誉属于游戏推演，不是现实比赛预测；球队或奖项信息不保证与实时赛季同步。

## 存档与使用

- 游戏运行于浏览器，进度使用本地双人存档；同一设备的浏览器通常会自动保存。清理浏览器数据、换设备或浏览器存储空间不足时可能丢失未备份进度。
- 在游戏的存档页面可导出或导入 JSON，也可创建本机备份；本机备份不能替代导出文件。导入和重开会按页面提示处理已有进度，建议先自行导出备份。
- 原有双人存档键继续使用。旧档不会为了新版玩法被自动删除；如出现无法识别或不兼容的旧档，应先导出备份再操作。

## 本地开发和检查

在仓库根目录运行 `python3 -m http.server 8080`，再访问 `http://localhost:8080/football-legacy/`。游戏使用本地 HTML、CSS 和 JavaScript；玩家无需安装 Python。Python 3 标准库工具仅供开发者离线检查球队数据结构，不访问网络、也不读取或修改存档：

```bash
node football-legacy/tests/smoke.cjs
python3 football-legacy/tools/audit_clubs.py
python3 -m unittest discover -s football-legacy/tests -p 'test_audit_clubs.py'
```

球队审计只能检查结构、名称和重复项，**不能证明俱乐部确实参加了现实中的某个赛季**。

## v5.0 六档转会分级（游戏设定）

球队不再按“中超/非五大/五大/豪门”四档笼统归类，而是按俱乐部声望分为六档：中超 → 欧洲非五大普通球队 → 欧洲非五大豪门（如本菲卡、波尔图、阿贾克斯） → 五大联赛普通球队 → 五大联赛豪门 → 世界传奇豪门（例如皇家马德里、巴塞罗那、巴黎圣日耳曼、曼城、曼联）。巴黎圣日耳曼属于传奇档。每赛季最多升级一档，进球、助攻、出场、评分和能力需要达标。

降档必须转到更低的一档；处于中超起点的球员，连续表现不佳不会强制在中超球队之间转会并伪称“降档”，而是可以留队或进行正常的同级转会。旧档案保留，转会考核在下一次赛季结算时刷新。以上分档是游戏玩法设计，并非现实俱乐部官方排名。


## v5.2：100赛季统计校准与开源方法借鉴

先在 v5.1 不修改游戏逻辑的情况下，以10组固定种子，每组模拟两名球员各10个赛季，总计100个共享赛季（200个球员赛季）。基线显示：200个球员赛季中198个赛季滞留中超，只有1次成功升档；平均13.02球、9.2次助攻，最高24球。原比分模型压低进球后没有同步调整球员评分，实际场均6.3～6.6却要求至少6.8以上，故评分合格率极低。

v5.2 将比赛评分基准校准至适当范围，并基于角色、比赛出场、进球、助攻和综合属性逐档设置门槛。球员打进20球不再因旧版过低评分公式误判低迷。仍坚持每季最多升一档；中超内部同档转会无论何种原因都不记为升档；连续两个无冠赛季可同档换队，表现长期低迷时降档优先。

开源方法参考（只借鉴算法思想，未复制第三方项目代码，也未将Python依赖打包进浏览器）：
- [penaltyblog](https://github.com/martineastwood/penaltyblog)（MIT）：使用泊松进球分布和强弱队期望进球差，避免简单均匀随机比分。
- [socceraction](https://github.com/ML-KULeuven/socceraction)（MIT）：借鉴按位置、场景评估动作贡献的原则，将进球与助攻贡献、比赛结果和对手强度纳入评分。当前游戏没有事件级传球与射门流，**不声称已经实现官方 VAEP 或 xT**。
- [soccerdata](https://github.com/probberechts/soccerdata)：借鉴统一的联赛数据接口，为各联赛设置公开可调的进球环境参数。**参数暂时是游戏平衡系数，未经2026真实数据校准；没有在线爬取任何足球数据库**。未来可以在本地研究环境整理经许可的赛季数据后更新参数，不在浏览器内运行Python爬虫。

性能回归：`node football-legacy/tests/balance-100.cjs`，输出全部赛季的平均进球、助攻、评分、球员档位、升降档次数、金球奖分布和极端值。GitHub Actions 每次修改核心引擎都会跑这一基准；该实验为模拟样本统计而非对未来赛季的预测。


## v5.4：成长、表现和真实升降档（2026-11-11）

针对 v5.3 的 1000 次独立开档 × 10 赛季回归发现的升档频繁、降档为零、成长过快等缺陷，加入独立随机赛季状态影响比赛参与、射门、助攻及评分，按当前位置所在俱乐部档次与位置设置预期进攻产出和连续低迷识别，引入每季持久的球探评估机会，提高升档准入要求。年龄和训练成长减速，30岁起出现与年龄相关的身体衰退，严重伤病可在换季后继续停赛，不再在新年自动清零。

晋升和降档仍由用户抽取目标档次球队，同档连续两季无冠由系统自动随机转会；所有球队层级顺序不变，不会把中超换中超称为升档。历史存档不批量重写，变化将应用在后续模拟的赛季。

增加了 `tests/stress-1000.cjs` 可复现压力测试（每个样本双人模拟10赛季）；GitHub Actions `football-stress-1000.yml` 支持并行运行 1000 次独立样本。正式版本发布后需重新运行独立 100 样本测试，以确认正式主分支和修复分支的行为一致。


## 16岁双主角中超青训开局（v5.7）

新建双人生涯时继续使用原来的**王楚淇和维尼修斯**两张人物卡，均设为中国游戏国籍。真实身份资料（如成年身高、出生日期）与虚构的青训故事分开说明。王楚淇沿用「18岁姆巴佩 FIFA 18」能力模板、维尼修斯沿用「18岁维尼修斯 FIFA 19」能力模板，**16岁具体技能在各自的模板基础上作青年化下调，不是两位球员真实的16岁官方能力数据**；后续潜力仍沿用原设定。

开局两次旋转抽签，从既有赛程与2026中超名单的14支俱乐部交集中分别随机进入**真实中超俱乐部的虚构青训梯队**（不接受自行挑队，两人默认分属不同球队）。2026和2027赛季分别为16岁和17岁青年阶段，只有共享的中超青训联赛，没有正式中超联赛、国家队或欧战；青年赛季出场、进球、助攻和荣誉仅记录在青训履历，不计入成年职业生涯、正式中超金靴、连续无冠转会或金球奖资格。18岁（2028赛季）自动升入各自抽中的中超一线队，仍然共享同一世界、联赛和奖项，并在其后按照既有六档升降级和抽签规则开展职业生涯。

升级已存在的 v5.4 双人存档**不会强行让已有成年球员变回16岁**，也不会覆盖正在进行中的职业生涯。只有点击「新游戏」重新开档才应用青训起步规则；建议重开前导出 JSON 备份。

青训联赛冠军不会写入成年联赛冠军历史；由于目前没有完整青年球员射手数据库，青训榜单仅比较两名主角，并不声称代表整个联赛。

## v5.8：统一欧冠/欧联、纪律与休赛期恢复

- 在**同一世界、同一赛季、同一赛事**里，欧冠/欧联只有一套36队联赛阶段、八轮对阵、唯一积分榜、淘汰赛赛程、决赛和冠军。两名球员若同时参加欧冠，读取同一个共享赛事数据源，不再分别抽签；可能对阵，也可能各自出局。冠军可以是NPC所属球队，绝不保证一定是主角球队。
- 旧档如果已经开始欧战，不会中途覆写已经发生的比分；后续新赛季切换共享欧战逻辑。旧版同年重复冠军声明的校正会在荣誉馆公开说明，校正不是对历史上从未发生的统一决赛做真实复原。
- 伤停状态按自己球队的比赛逐场扣减；休赛期恢复部分体能和伤情，长期伤病可持续到下一赛季。
- 联赛、欧冠/欧联、国内杯和国家队使用不同的黄牌累计与停赛计数，不能用国内杯抵消联赛停赛或反过来；单场红黄牌不会同时抽中。季末黄牌清零，未执行禁赛跨季保留。
- 双人卡片显示当前伤停、联赛/欧战/杯赛/国家队剩余禁赛及红黄牌情况。所有游戏规则和数值均为模拟，非对现实赛事的断言。
- 使用 `tests/smoke.cjs` 验证2048年巴黎与巴萨同一届欧冠共享赛程、只有一个冠军、存档重载，以及禁赛按赛事隔离与长期伤病；另外保留100赛季与1000次样本测试。

## v8.1.0：身高与体重相互制衡、双人独立开局路线（2026-11-13）

- 经典模式下，王楚淇和维尼修斯均可在翻牌前独立选择8种场上位置、45–125kg体重及成长路线；原始两个球员的能力模板和随机卡规则不变。位置会参与位置加权的游戏综合评分，不会凭空增加原始能力。
- 快速造星按身高生成相近的起始体重（原有位置化身高范围保留）；自定义模式可在150–210cm身高与45–125kg体重之间自由设定，设置在球队卡翻开时锁定并保存。初始随机潜能不由身高/体重、国籍、性别、族裔或肤色决定。
- 体格修正是**有上限且相互制衡的游戏参数**：更高有利高空球与门将覆盖，略损灵活；更重有利对抗，略损灵活与续航；较轻偏灵活，空中对抗可能稍弱。不同场上位置综合权重不同。身体影响实际比赛的个人参与机会、评分微调、首发竞争和体能消耗，但**不是**完整物理碰撞模拟，更不是现实中每个人的能力定论。
- 开局发展方向有三种：**均衡发展**（维持原有训练与出场节奏）、**成长优先**（减少训练的升级次数要求，但略降低上场机会）、**出场优先**（提高出场与首发机会，但能力训练积累相对较慢）。均为概率／训练机制，不保证首发或达到隐藏潜能。
- 旧存档没有体格数据时使用中性模拟系数，不会把推算值写入旧档，也不会更改原有年龄、能力、荣誉、国籍或30年生涯历史。原有35岁后衰退、40岁退休、十张球队盲卡和双人统一世界机制继续保留。

## v10.0.1 双星深度生涯可操作化（2026-11-13）

- 双人职业生涯现在可以从首页「双星训练中心」进入，分别设置轻松生涯或深度生涯。轻松模式自动训练及分配成长点；深度模式可按每名球员的实际进度亲自进行专项训练、消耗能力点和恢复体能。
- 深度模式每场比赛前每名球员只能选择一次「专项训练」或「恢复」，不提供免费的额外能力。训练按原有年龄与成长路径公式积累进度；受伤时不能专项训练，体能低于23不能继续训练。
- 修复更换「训练偏向」会错误开启自动加点和自动训练的问题；深度模式被视为权威，即使旧版本将自动标记误写为开启，也不会在比赛中偷偷自动训练。
- 在深度模式下使用「快进7个比赛日」或「模拟剩余赛季」，会提醒手动训练机会将被跳过；可以改为每天推进并手动安排。
- 两名球员训练状态互相独立，更新不批量改写历史存档、球员数值和已获得荣誉。浏览器空间不足时，手动指令、操作模式和训练偏向更改会回滚；如需跨设备保存，请导出 JSON。
