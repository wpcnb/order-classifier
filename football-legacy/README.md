# 绿茵世代 · 双人职业生涯

在线试玩：https://wpcnb.github.io/order-classifier/football-legacy/

## 当前游戏模式

开局固定两张可操作球员卡，两人的起始俱乐部由两个中超球队转盘分别随机抽取，不能直接选择皇家马德里，也不会预设成都蓉城：
- **王楚淇**：中国球员身份资料（1999-02-06、177 cm），采用《FIFA 18》18岁姆巴佩的历史能力模板，初始综合83、潜力94。
- **维尼修斯**：球员身份资料（2000-07-12、176 cm、现实国籍巴西），采用《FIFA 19》18岁维尼修斯的历史游戏能力模板，初始综合77、潜力92。

**两张卡都从18岁、中国游戏国籍开始。** 维尼修斯的中国籍是架空游戏设定，不是事实；王楚淇的FIFA评分是借用姆巴佩模板，也不代表真实能力评级。实际出生日期与游戏年龄分别保存。

**两名球员共享同一足球世界**、共同的中超赛程、比赛结果与积分榜；两人可以分属不同中超球队，并在联赛主客场直接交锋。日期同步推进，所有比赛只计算一次，避免两张球员卡出现相互矛盾的比分。每个人独立保留能力成长、进球助攻、伤病停赛、转会和个人荣誉，切换球员只切换操作对象，不会生成另一套联赛。

## 表现与降档

赛季结束根据球员位置、球队强弱、实际出场次数、进球与助攻以及评分评价表现；进攻球员出场少于15场、非进攻位置免于简单的进球助攻降档处罚。连续两个赛季表现显著不足，在五大联赛效力的球员须降低职业平台，接受更弱球队或非五大联赛（包括中超）机会。良好表现可重新获得更强队报价。伤病、赛程和模拟数据均为游戏生成。

## 使用说明

- 唯一正式在线入口为本目录的 `index.html`，仓库根目录自动跳转到该入口。
- 不再维护独立离线版。双人模式使用 `football-dynasty-duo-v2-20261110` 浏览器存储键。旧版 v4 与双人 v1 存档及保险备份不会自动删除，也不会自动转换；如本设备仍有旧档，可在开局或存档页面导出备份。
- 游戏浏览器存档、保险备份、JSON导出与导入均为**双人存档**。清除浏览器数据后无法找回，建议主动导出。
- 自动回归测试位于 `tests/smoke.cjs` 与 `tests/match-strategy.cjs`；核心引擎是 `game.js`。
- 不读取外部实时足球数据；球队、能力、赛季赛果、转会和获奖为模拟，并非官方预测。

## 本地开发

运行 `python -m http.server 8080`，访问 `/football-legacy/`。这是纯静态 HTML/JS 游戏，无需安装依赖。


## v4.9 轻量存档与中超能力转化

- 不设球员切换按钮，王楚淇与维尼修斯一直并排显示，一键推进同一个足球世界。
- 精简保存内容：AI球员名册、世界积分和模拟赛程不再在两套球员档案里重复保存；只保留单份共享数据，完整赛程加载时按联赛重建。原 v2 存档可自动转换，仍支持 JSON 导入与导出。
- 中超高能力球员的比赛贡献与本人射门、传球、综合实力和对手强度挂钩。每场个人进球与助攻来自真实模拟的本队进球，不会凭空增加，双方同场比分和联赛奖项保持一致。
- 旧个人存档与保险备份不会被不经确认地删除。可自行从游戏的「共同存档」导出备份。

## v5.0 六档转会分级（游戏设定）

球队不再按“中超/非五大/五大/豪门”四档笼统归类，而是按俱乐部声望分为六档：中超 → 欧洲非五大普通球队 → 欧洲非五大豪门（如本菲卡、波尔图、阿贾克斯） → 五大联赛普通球队 → 五大联赛豪门 → 世界传奇豪门（例如皇家马德里、巴塞罗那、巴黎圣日耳曼、曼城、曼联）。巴黎圣日耳曼属于传奇档。每赛季最多升级一档，进球、助攻、出场、评分和能力需要达标。

降档必须转到更低的一档；处于中超起点的球员，连续表现不佳不会强制在中超球队之间转会并伪称“降档”，而是可以留队或进行正常的同级转会。旧档案保留，转会考核在下一次赛季结算时刷新。以上分档是游戏玩法设计，并非现实俱乐部官方排名。


## v5.2：100赛季统计校准与开源方法借鉴

先在 v5.1 不修改游戏逻辑的情况下，以10组固定种子，每组模拟两名球员各10个赛季，总计100个共享赛季（200个球员赛季）。基线显示：200个球员赛季中198个赛季滞留中超，只有1次成功升档；平均13.02球、9.2次助攻，最高24球。原比分模型压低进球后没有同步调整球员评分，实际场均6.3～6.6却要求至少6.8以上，故评分合格率极低。

v5.2 将比赛评分基准校准至适当范围，并基于角色、比赛出场、进球、助攻和综合属性逐档设置门槛。球员打进20球不再因旧版过低评分公式误判低迷。仍坚持每季最多升一档；中超内部同档转会无论何种原因都不记为升档；连续两个无冠赛季可同档换队，表现长期低迷时降档优先。

开源方法参考（只借鉴算法思想，未复制第三方项目代码，也未将Python依赖打包进浏览器）：
- [penaltyblog](https://github.com/martineastwood/penaltyblog)（MIT）：使用泊松进球分布和强弱队期望进球差，避免简单均匀随机比分。
- [socceraction](https://github.com/ML-KULeuven/socceraction)（MIT）：借鉴按位置、场景评估动作贡献的原则，将进球与助攻贡献、比赛结果和对手强度纳入评分。当前游戏没有事件级传球与射门流，**不声称已经实现官方 VAEP 或 xT**。
- [soccerdata](https://github.com/probberechts/soccerdata)：借鉴统一的联赛数据接口，为各联赛设置公开可调的进球环境参数。**参数暂时是游戏平衡系数，未经2026真实数据校准；没有在线爬取任何足球数据库**。未来可以在本地研究环境整理经许可的赛季数据后更新参数，不在浏览器内运行Python爬虫。

性能回归：`node football-legacy/tests/balance-100.cjs`，输出全部赛季的平均进球、助攻、评分、球员档位、升降档次数、金球奖分布和极端值。GitHub Actions 每次修改核心引擎都会跑这一基准；该实验为模拟样本统计而非对未来赛季的预测。


## v5.4：成长、表现和真实升降档（2026-11-11）

针对 v5.3 的 1000 次独立开档 × 10 赛季回归发现的升档频繁、降档为零、成长过快等缺陷，加入独立随机赛季状态影响比赛参与、射门、助攻及评分，按当前位置所在俱乐部档次与位置设置预期进攻产出和连续低迷识别，引入每季持久的球探评估机会，提高升档准入要求。年龄和训练成长减速，30岁起出现与年龄相关的身体衰退，严重伤病可在换季后继续停赛，不再在新年自动清零。

晋升和降档仍由用户抽取目标档次球队，同档连续两季无冠由系统自动随机转会；所有球队层级顺序不变，不会把中超换中超称为升档。历史存档不批量重写，变化将应用在后续模拟的赛季。

增加了 `tests/stress-1000.cjs` 可复现压力测试（每个样本双人模拟10赛季）；GitHub Actions `football-stress-1000.yml` 支持并行运行 1000 次独立样本。正式版本发布后需重新运行独立 100 样本测试，以确认正式主分支和修复分支的行为一致。


## 16岁双主角中超青训开局（v5.7）

新建双人生涯时继续使用原来的**王楚淇和维尼修斯**两张人物卡，均设为中国游戏国籍。真实身份资料（如成年身高、出生日期）与虚构的青训故事分开说明。王楚淇沿用「18岁姆巴佩 FIFA 18」能力模板、维尼修斯沿用「18岁维尼修斯 FIFA 19」能力模板，**16岁具体技能在各自的模板基础上作青年化下调，不是两位球员真实的16岁官方能力数据**；后续潜力仍沿用原设定。

开局两次旋转抽签，从既有赛程与2026中超名单的14支俱乐部交集中分别随机进入**真实中超俱乐部的虚构青训梯队**（不接受自行挑队，两人默认分属不同球队）。2026和2027赛季分别为16岁和17岁青年阶段，只有共享的中超青训联赛，没有正式中超联赛、国家队或欧战；青年赛季出场、进球、助攻和荣誉仅记录在青训履历，不计入成年职业生涯、正式中超金靴、连续无冠转会或金球奖资格。18岁（2028赛季）自动升入各自抽中的中超一线队，仍然共享同一世界、联赛和奖项，并在其后按照既有六档升降级和抽签规则开展职业生涯。

升级已存在的 v5.4 双人存档**不会强行让已有成年球员变回16岁**，也不会覆盖正在进行中的职业生涯。只有点击「新游戏」重新开档才应用青训起步规则；建议重开前导出 JSON 备份。

青训联赛冠军不会写入成年联赛冠军历史；由于目前没有完整青年球员射手数据库，青训榜单仅比较两名主角，并不声称代表整个联赛。

## v5.8：统一欧冠/欧联、纪律与休赛期恢复

- 在**同一世界、同一赛季、同一赛事**里，欧冠/欧联只有一套36队联赛阶段、八轮对阵、唯一积分榜、淘汰赛赛程、决赛和冠军。两名球员若同时参加欧冠，读取同一个共享赛事数据源，不再分别抽签；可能对阵，也可能各自出局。冠军可以是NPC所属球队，绝不保证一定是主角球队。
- 旧档如果已经开始欧战，不会中途覆写已经发生的比分；后续新赛季切换共享欧战逻辑。旧版同年重复冠军声明的校正会在荣誉馆公开说明，校正不是对历史上从未发生的统一决赛做真实复原。
- 伤停状态按自己球队的比赛逐场扣减；休赛期恢复部分体能和伤情，长期伤病可持续到下一赛季。
- 联赛、欧冠/欧联、国内杯和国家队使用不同的黄牌累计与停赛计数，不能用国内杯抵消联赛停赛或反过来；单场红黄牌不会同时抽中。季末黄牌清零，未执行禁赛跨季保留。
- 双人卡片显示当前伤停、联赛/欧战/杯赛/国家队剩余禁赛及红黄牌情况。所有游戏规则和数值均为模拟，非对现实赛事的断言。
- 使用 `tests/smoke.cjs` 验证2048年巴黎与巴萨同一届欧冠共享赛程、只有一个冠军、存档重载，以及禁赛按赛事隔离与长期伤病；另外保留100赛季与1000次样本测试。


## v6.3.0：自由造星与随机隐藏潜能（2026-11-13）

- 开局支持三种模式：**经典双星**（原王楚淇与维尼修斯预设不变）、**快速造星**（随机人物资料）、**自定义造星**（两人分别选择国籍、16–39岁、150–210厘米、性别、可选族裔/地区背景、肤色、发型与场上位置）。
- 随机潜能一次生成并写入创建阶段的锁定存档。潜能分布为65–79（45%）、80–89（35%）、90–94（15%）、95–99（5%）；在游戏 UI 中隐藏精确潜能，随着完成的赛季数显示逐渐收窄的球探估计区间。历史预设评分不受影响。
- 性别、国籍、族裔背景和肤色**不参与属性或潜能计算**；球员能力根据随机潜能、场上位置与独立随机数生成。身份外观不暗示竞技能力、身体素质或人格。
- 自定义年龄16–17岁从抽中球队的青训开始；18–39岁直接进入抽中俱乐部一线队。35岁后逐年身体衰退、年满40岁自动退役，以及每人亲自翻开10张球队卡的规则仍然保留。
- 自定义性别球员使用**架空混合赛事**，不会冒充真实女子或男子职业赛事的资格与赛程规则。
- 头像由本地固定 SVG 图层组成，不调用线上人脸模型；各自使用独立的肤色与发型配置，并且每次刷新/读档保持一致。人物形象不改变能力。
- 首次翻牌同时锁定球队及角色生成记录；如存储失败则回滚，不发生刷新重新抽取潜能。两个角色仍处于共享世界，各自有独立隐藏潜能与职业档案。
- 旧版 v2 双人存档与当前 v6.2.0 职业深度系统兼容，老存档不会自动生成或改写隐藏潜能。若希望改为新人物，须自行导出旧档备份后重开。

## v8.0.1 男子职业生涯开局修正（2026-11-13）

- 目前游戏只模拟男子职业联赛：新建快速及自定义虚构球员性别固定为男，不再出现女子/非二元人物直接参加现有中超等男子比赛。原始经典双星模板不受影响。
- 快速造星不再统一抽取158–199cm；按场上位置使用不同合理身高区间，例如门将183–203cm、中后卫180–201cm、边锋166–187cm。身高限制只是快速造星的默认设计，不代表现实足球运动员身高标准。
- 自定义球员仍可自由设置150–210cm；球员外貌、国籍、肤色及族裔背景不会决定比赛潜能或属性。当前身高暂不直接作用于比赛争顶或扑救计算，未来可以加入独立位置机制并进行平衡验证。
- 已经开始的历史双人生涯存档不会被自动改写（包括旧版不同性别设定）；读取旧存档不会重新抽取潜能、球队或更改年龄。旧版已翻牌但尚未正式开局的角色创建，在新模式生成职业球员时使用男性设定，但保留已锁定潜能、球员能力和球队卡结果。
- 默认不额外增加首页按钮；人物创建面板显示「男（固定）」并说明当前版本为男子赛事。
