# 绿茵世代 · 双人职业生涯

在线试玩：https://wpcnb.github.io/order-classifier/football-legacy/

## 当前游戏模式

开局固定两张可操作球员卡，两人的起始俱乐部由两个中超球队转盘分别随机抽取，不能直接选择皇家马德里，也不会预设成都蓉城：
- **王楚淇**：中国球员身份资料（1999-02-06、177 cm），采用《FIFA 18》18岁姆巴佩的历史能力模板，初始综合83、潜力94。
- **维尼修斯**：球员身份资料（2000-07-12、176 cm、现实国籍巴西），采用《FIFA 19》18岁维尼修斯的历史游戏能力模板，初始综合77、潜力92。

**两张卡都从18岁、中国游戏国籍开始。** 维尼修斯的中国籍是架空游戏设定，不是事实；王楚淇的FIFA评分是借用姆巴佩模板，也不代表真实能力评级。实际出生日期与游戏年龄分别保存。

**两名球员共享同一足球世界**、共同的中超赛程、比赛结果与积分榜；两人可以分属不同中超球队，并在联赛主客场直接交锋。日期同步推进，所有比赛只计算一次，避免两张球员卡出现相互矛盾的比分。每个人独立保留能力成长、进球助攻、伤病停赛、转会和个人荣誉，切换球员只切换操作对象，不会生成另一套联赛。

## 表现与降档

赛季结束根据球员位置、球队强弱、实际出场次数、进球与助攻以及评分评价表现；进攻球员出场少于15场、非进攻位置免于简单的进球助攻降档处罚。连续两个赛季表现显著不足，在五大联赛效力的球员须降低职业平台，接受更弱球队或非五大联赛（包括中超）机会。良好表现可重新获得更强队报价。伤病、赛程和模拟数据均为游戏生成。

## 使用说明

- 唯一正式在线入口为本目录的 `index.html`，仓库根目录自动跳转到该入口。
- 不再维护旧版《陆白》存档或独立离线版。新模式使用 `football-dynasty-duo-v2-20261110` 浏览器存储键，并在加载时清除原 v4 旧键及双人旧版 v1 存档。
- 游戏浏览器存档、保险备份、JSON导出与导入均为**双人存档**。清除浏览器数据后无法找回，建议主动导出。
- 自动回归测试位于 `tests/smoke.cjs` 与 `tests/match-strategy.cjs`；核心引擎是 `game.js`。
- 不读取外部实时足球数据；球队、能力、赛季赛果、转会和获奖为模拟，并非官方预测。

## 本地开发

运行 `python -m http.server 8080`，访问 `/football-legacy/`。这是纯静态 HTML/JS 游戏，无需安装依赖。


## v4.9 轻量存档与中超能力转化

- 不设球员切换按钮，王楚淇与维尼修斯一直并排显示，一键推进同一个足球世界。
- 精简保存内容：AI球员名册、世界积分和模拟赛程不再在两套球员档案里重复保存；只保留单份共享数据，完整赛程加载时按联赛重建。原 v2 存档可自动转换，仍支持 JSON 导入与导出。
- 中超高能力球员的比赛贡献与本人射门、传球、综合实力和对手强度挂钩。每场个人进球与助攻来自真实模拟的本队进球，不会凭空增加，双方同场比分和联赛奖项保持一致。
- 旧个人存档与保险备份不会被不经确认地删除。可自行从游戏的「共同存档」导出备份。

## v5.0 六档转会分级（游戏设定）

球队不再按“中超/非五大/五大/豪门”四档笼统归类，而是按俱乐部声望分为六档：中超 → 欧洲非五大普通球队 → 欧洲非五大豪门（如本菲卡、波尔图、阿贾克斯） → 五大联赛普通球队 → 五大联赛豪门 → 世界传奇豪门（例如皇家马德里、巴塞罗那、巴黎圣日耳曼、曼城、曼联）。巴黎圣日耳曼属于传奇档。每赛季最多升级一档，进球、助攻、出场、评分和能力需要达标。

降档必须转到更低的一档；处于中超起点的球员，连续表现不佳不会强制在中超球队之间转会并伪称“降档”，而是可以留队或进行正常的同级转会。旧档案保留，转会考核在下一次赛季结算时刷新。以上分档是游戏玩法设计，并非现实俱乐部官方排名。
