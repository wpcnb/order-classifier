# 福彩3D概率研究

研究目的：用全部1000种等概率结果校验概率、回报和风险；用固定随机基准评估任何历史模型，不声称能预测随机开奖。

执行 `git submodule update --init --recursive` 获取外部源码。各项目保留独立许可、作者及依赖；先审查再执行，尤其不要在含凭据环境直接运行上游代码。仅固定引用，尚未实现四套算法统一接口或完成回测。

## 模拟摇奖机

在[公开首页](https://wpcnb.github.io/order-classifier/)点「开始摇奖」，或运行 `python lottery-research/probability.py --draw` 生成一组三位号码。三个位置各自从 0–9 等概率抽取，保留前导零和重复数字。网页使用 Web Crypto，对字节 250–255 重抽以消除取模偏差。Python 返回可直接交给 `payout` 的数字元组。网页记录仅保留本页最近十次模拟。

气动搅拌演示参考[福彩公开的 Topaze 设备参数](https://www.szlottery.org/fcw/fcxw/csdt/content/post_752635.html)、[三仓结构、颜色对应和顶部出球位置](https://caipiao.people.com.cn/n1/2015/1231/c373276-27999921.html)及[福彩 3D 开奖规则](https://www.swlc.net.cn/games/3d.html)。画面布局、球路和时长用于演示。公开规格不足以复原当期现场气流和每一颗球的实际运动。运行 `node --test lottery-research/test_draw.mjs` 核对网页采样。

### 单次和值展示

三个数字全部揭晓后显示和值（0–27），新动画开始时清空和值；历史回放与随机模拟使用同一计算方法，回放不增加模拟记录。从头播放不重复记录。最近十次模拟记录同时列出号码和和值。此功能不改变抽样逻辑。

### 本机模拟存档

每次完成随机模拟后保存号码、和值、唯一记录编号和完成时间（界面显示北京时间），最近10条在首页显示，完整本机存档最多保留1000条，可导出 JSON。刷新后恢复；历史回放及同次重播不重复入账。浏览器禁用存储或存档损坏时提示并保留本页记录，不覆盖损坏数据。非云同步，不补录旧版未保存结果；并行标签页同时写入仍可能产生竞争。此功能不影响随机数。

### 三维观察基础（第一轮）
  
在原摇奖台点击「切换三维观察」进入可选 WebGL 展示，支持四个固定视角。三维机体、三仓、出球管、支架、设备柜、数字球、灯光均用几何体与程序纹理生成。三维层只读取现有平面动画的球位置和已揭晓数字，不调用抽样、不写存档，停止时释放渲染资源；加载失败、WebGL 不可用或上下文丢失时回到平面模式。该版为几何及动画展示，不是物理求解器或精确实机复刻。未接入 Rapier、外部模型或实测气流。

依赖：[Three.js 0.186.1](https://www.jsdelivr.com/package/npm/three?version=0.186.1)（MIT，[许可证](https://github.com/mrdoob/three.js/blob/r186/LICENSE)；[安装文档](https://threejs.org/manual/pages/installation.html)）。浏览器主动切换时通过固定版本 CDN 加载，网络失败不影响基础模拟；CI 用同版本本地 npm 包进行 WebGL 与故障回退验收。下一步建议在三维展示层增加独立刚体演示，不参与正式模拟号码生成。

### 第二轮：独立刚体碰撞实验

采用 [Rapier JS 0.21.0](https://www.npmjs.com/package/@dimforge/rapier3d-compat/v/0.21.0)（Apache-2.0，[官方文档](https://rapier.rs/docs/user_guides/javascript/getting_started_js/)）及既有 Three.js。独立透明箱体内六颗无编号球，演示重力、碰撞、摩擦、反弹和旋转；固定 60Hz 步长，最长8秒，可选择三档反弹系数、暂停、复位。减弱动态效果时逐帧推进；关闭释放资源，加载失败不影响基础页面。参数为教学示意，非真实气流、机械测量或开奖号码生成模型。此模块不调用原抽样或存档接口。CI 包含真实 WASM 数值边界检查和浏览器失败回退、复位、存档隔离测试。

### 第二轮接入：主机三仓刚体展示

在三维观察中点击「启用三仓碰撞演示」，原摇奖动画的时间戳驱动 30 个 Rapier 球体，使用固定步长、每帧有限追赶与球形边界近似。暂停、半速、复位、逐仓揭晓同步原逻辑；恢复普通三维模式及关闭时释放世界。重力、推动场和边界反弹为视觉参数，不是真实气动求解；碰撞层不读取未来号码、不负责选择出球、不会改变随机性或写入记录。减弱动态效果时保持几何模式。独立实验室继续可用。共享固定版本 Rapier 懒加载；引擎失败只回退三维几何动画。

### 第三轮：PBR 材质与演播室灯光

使用已有 Three.js 的 MeshPhysicalMaterial、PMREMGenerator 以及原创程序纹理，为金属增加粗糙度纹理与环境反射，为数字球增加清漆高光。透明球仓提供默认均衡和可选光学透射两档；三套直接照明配色为冷暖、中性及紫蓝。环境反射使用六块程序生成灯板，不依赖外部 HDRI、照片或新增第三方库；PMREM 生成失败时保留直接照明。精细模式限制像素比以减轻负载；三维关闭时释放环境目标和纹理。参数只是展示设定，不是实机光学测量。参考：https://threejs.org/docs/pages/MeshPhysicalMaterial.html 与 https://threejs.org/docs/pages/PMREMGenerator.html 。浏览器回归覆盖环境生成、材质切换、灯光、相机、抽样和存档不变。

### 最近10次滚动最高频统计

在本机模拟记录下显示各位置最高频组合、最高频和值、三位合计最高频数字和完整频数。每次完成模拟、刷新及同源存档变化自动重算。按最新10条完成记录统计，未满10条显示实际样本；并列全部保留，前导零保留，不额外抽样，不计入历史回放或物理实验。仅描述历史频数，不是开奖预测或投注建议。

### 页面只显示最近10条

移除完整存档列表的 DOM 渲染，页面最多展示10条模拟记录，最高频统计窗口保持10条。较早记录不删除，仍按原本机存档上限保存，可通过 JSON 导出备份。历史官方开奖区不受影响。

### 紧凑双列面板

桌面端左列摇奖台及最近10条模拟记录，右列顶部最高频统计、下方本次号码和控制；宽屏扩大内容区，紧凑统计行避免多列窄卡造成空白，手机端依次显示摇奖台、统计及控制、最近记录。保留全部原 DOM 数据 ID 与统计逻辑，增加390/1024/1440像素响应式位置和溢出回归。

### 全部本机存档最高频统计

右侧三项改为基于所有当前留存的本机完成模拟（现有上限1000条），而非可见的最近10条；只显示最高频数值，隐藏频次与频数明细。并列保留，已丢失或超过保存上限的历史不能恢复。历史回放与官方数据不计入，统计不构成预测。

### 快速连抽与本次报告

「10 连抽」「100 连抽」「1000 连抽」各使用原有 Web Crypto 等概率抽样器逐组独立生成，号码允许重复，全部生成成功后一次写入已有本机存档；摇奖机只播放最后一组，重播不重复入账。动画可选正常、半速、2倍速或4倍速，速度不影响抽样结果。存档仍最多1000条、页面只显示最近10条，1000连抽会替换此前留存的记录，应先导出所需备份。同毫秒内的记录按实际抽取顺序排列，旧存档无需迁移。

最近一次连抽报告展示样本数、不同号码数、重复次数（总数减去不同号码数）、平均和值、号码类型、最高频和值和各位数字频数。报告是本次连抽的聚合统计，独立于全部本机存档的最高频统计；只保存聚合结果，不另存一份号码历史。刷新恢复后仍可查看。若随机数服务失败则整批不入账；本机存储失败或损坏时保留当前页面数据并提示导出，不覆盖损坏存档。统计不代表未来开奖概率变化。

### v1.1.0 · 直接看结果（2026-11-27）

### v1.2.0 · 连抽直接显示结果（2026-11-27）

在「快速连抽」下勾选「连抽直接显示结果」，10、100、1000 连抽会立即显示最后一组号码、和值和整批报告。设置默认关闭，并保存在当前浏览器。单抽、历史回放及「从头播放」沿用原播放方式。

### v1.3.0 · 连抽和值分布（2026-11-27）

展开最近一次连抽报告的「查看和值分布」，可逐项核对 0–27 的出现次数和样本占比，以及从 000–999 的 1000 种等概率结果算出的理论占比。未出现的和值也会显示。新版读取现有连抽报告保存的和值数据，刷新后可恢复，无需重抽或转换存档。

### v1.4.0 · 下载连抽和值分布（2026-11-28）

点「下载和值分布（CSV）」可导出当前报告的 28 项和值统计，包括 UTC 批次时间、抽取次数、出现次数、样本占比和理论占比。CSV 使用带 BOM 的 UTF-8 编码。刷新恢复的报告也可直接下载。

### v1.5.0 · 记住动画速度（2026-11-28）

选择半速、正常、2 倍速或 4 倍速后，当前浏览器会记住设置，刷新或重新打开页面时自动恢复。首次访问或设置无效时使用正常速度。如果浏览器无法写入本地存储，所选速度仍在当前页面生效。

### v1.6.0 · 回放最近的模拟记录（2026-11-28）

最近 10 条本机模拟记录各有「回放」按钮。点按后跳转到结果区，按当前动画速度重看选中的号码和和值。回放可以暂停、跳过或重播。播放原记录不会新增抽样或写入存档，旧存档可直接使用。

### v1.7.0 · 按号码查找模拟记录（2026-11-28）

在「本机模拟记录」输入 1–3 位数字即可查找所留存的模拟记录。输入 `00` 可查找以 00 开头的号码，输入 `007` 则只找 007。页面显示匹配总数和最近 10 条匹配结果，每条可直接回放。清除搜索可返回最近记录。

### π 圆周运动及旋流演示

展示用户指定截断值 3.1415926，内部使用 Math.PI 全精度，以圈数换算弧度、黄金角分布初相位、正弦径向振荡、三维切向推动及周期升力，保持原60Hz步长、速度上限和球仓边界。该场为可视化近似而非实测气流；不改变独立均匀抽样、官方开奖或存档统计。加入轨迹有限性和边界回归。
