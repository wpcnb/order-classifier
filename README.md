当前仓库只维护《绿茵世代》在线版；历史经典版、离线版及其他旧小游戏已停止维护并从主干清理。

**在线游玩：** https://wpcnb.github.io/order-classifier/football-legacy/

**源代码：** `football-legacy/index.html`、`football-legacy/game.js` 和必要的脚本、素材、测试。

双人职业生涯：王楚淇（采用18岁姆巴佩能力模板）与维尼修斯（采用本人18岁历史游戏模板），两人按游戏中的中国籍、18岁设定开局，分别模拟成长、伤停、转会和奖项。
