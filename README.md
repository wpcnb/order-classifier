# 订单分类管理台

独立的中文静态网站，用来归类和复查2026年6—10月的订单。

## 隐私与发布

公开版 `index.html` **不包含真实付款记录**，不能通过查看公开网站源代码获取用户的交易明细。首次使用时，在页面右上角点「导入数据」，选择单独保管的 `订单数据_无交易单号.json`，151笔记录会存储在当前浏览器 `localStorage`。无需后端，也不会自动上传数据。

如需不导入即可直接开始使用，请在本地打开另外提供的 `订单管理_本地版_已导入151笔.html`。这份文件含私人账单信息，不要上传到公共GitHub仓库或公开网站。

## 主要功能

- 商户、收款人、备注、日期和金额搜索
- 按原账单类型、人工分类筛选；排序和翻页
- 逐笔选择分类，批量归类，自定义新增/重命名/删除分类
- 分类实时汇总金额与笔数
- 手动新增订单、删除选中订单、修改备注
- CSV导出；JSON导出和完整恢复（备份）
- 自适应手机和电脑界面；数据本机保存
- 原始微信交易单号和美团内部订单编号均不在站点源代码及导出文件中

## 部署到新 GitHub `wpcnb`

新建一个公共仓库（例如 `order-classifier`），只上传 `index.html` 和 `README.md`，在仓库 Settings -> Pages -> Build and deployment 选择 Deploy from a branch / main / root。公共站点URL通常为 `https://wpcnb.github.io/order-classifier/`。**不要**上传私人数据 JSON 或本地已导入的 HTML。

## 分类保存限制

网站使用浏览器本地存储，跨设备不会自动同步，清除浏览器数据可能导致分类丢失。每次完成一批归类，建议点击「备份数据」，需要时使用「导入数据」恢复。可在未来添加经鉴权的私有云同步。
